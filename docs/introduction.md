The optimizer chain detects file content and runs the matching tools in order.
Use the default chain, replace its optimizers, or implement the `Optimizer` trait for your own binary or service.

The PHP package documents its API in its README; its `docs` directory contains example images only.
This guide keeps the README's section names and ordering, with Spatie-style YAML navigation fields.
